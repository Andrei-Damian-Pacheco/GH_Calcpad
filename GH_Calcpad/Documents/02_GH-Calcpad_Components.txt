COMPONENTS GH_CALCPAD // VERSION 2.0.0
=======================================

INFORMATION & DIAGNOSTICS
==========================

a. GH_Calcpad_Info.cs ("Calcpad Info" / CP_Info)
Plugin information panel. Reads the worker's vendored Calcpad.Core.dll file metadata
directly (no in-process reference to Calcpad), so it always reflects whatever version the
worker actually calculates with.
INPUTS:
- (none)
OUTPUTS:
- PluginInfo: Item - string - GH_Calcpad version + author (Andrei Damian Pacheco)
- CalcpadInfo: Item - string - Calcpad.Core version + author/copyright

b. GH_Calcpad_Help.cs ("Calcpad Help" / CP_Help)
Static, always-available quick reference: workflows, one line per component, best
practices, examples.
INPUTS:
- (none)
OUTPUTS:
- Workflow: List - string
- ComponentGuide: List - string
- BestPractices: List - string
- Examples: List - string

FILE LOADING
=============

c. GH_Calcpad_Load_cpd.cs ("Load CPD" / LoadCPD)
Reads a .cpd/.txt file and extracts variables, values and units. Detects both the explicit
'var = ?{val}unit' placeholder format and plain literal assignments in a single pass (no
separate mode toggle - both are always recognized). Watches the file on disk and
auto-refreshes when it changes.
INPUTS:
- FilePath: Item - string - full path to the .cpd/.txt file
- Freeze: Item - bool, optional (default false) - acts as a switch: if True, blocks all
  output (no data passes downstream) and stops reading/watching the file
OUTPUTS:
- Variables: List - string - names of variables found, in file order
- Values: List - double - numeric values, 1:1 with Variables
- Units: List - string - units, 1:1 with Variables
- SheetObj (Sheet): Item - object - CalcpadSheet instance

VARIABLE MODIFICATION
=======================

d. GH_Calcpad_Search_Variables.cs ("Search Variables" / SearchVars)
Sets specific variables on a Sheet by name, before Play CPD. Clones the incoming Sheet
before writing to it, so wiring the same upstream Sheet into more than one branch never
lets one branch overwrite another's values.
INPUTS:
- Sheet: Item - object - CalcpadSheet (from Load CPD)
- Filter Names: List - string, optional - names to modify; leave empty/unconnected to
  auto-select every variable prefixed 'gh_'
- New Values: List - double - 1:1 with Filter Names (or with the auto-selected 'gh_'
  variables, in file order, if Filter Names is empty)
OUTPUTS:
- Sheet: Item - object - independent copy of the input Sheet with the requested variables
  set - connect to Play CPD
- Modified Names: List - string
- Modified Values: List - double
- Not Found: List - string - requested names not present in the Sheet

EXECUTION
==========

e. GH_Calcpad_Play.cs ("Play CPD" / PlayCPD)
The calculation engine. Takes a fully-prepared Sheet and runs it through Calcpad (the
worker process). Clones the incoming Sheet before calculating.
INPUTS:
- Sheet: Item - object - CalcpadSheet to calculate (from Load CPD or Search Variables)
OUTPUTS:
- Sheet: Item - object - calculated CalcpadSheet - connect to Search Results and/or Export
- Elapsed: Item - double - calculation time in milliseconds
- Success: Item - bool - true if calculation succeeded (check this before trusting
  downstream results, especially inside an optimization loop)

RESULT FILTERING
=================

f. GH_Calcpad_Search_Results.cs ("Search Results" / SearchRes)
Reads specific computed results from a calculated Sheet by name, straight from the
worker's authoritative result set (no source-text scanning for values/units).
INPUTS:
- Sheet: Item - object - calculated CalcpadSheet (from Play CPD)
- Filter Names: List - string, optional - names to read; leave empty/unconnected to
  auto-select every result prefixed 'ghc_'
OUTPUTS:
- Equations: List - string - 'Name = expression' for each match (falls back to
  'Name = value unit' when no source formula exists, e.g. plain inputs)
- Values: List - double
- Units: List - string

SAVING & EXPORT
================

g. GH_Calcpad_Save_cpd.cs ("Save CPD/TXT" / SaveCPD)
Writes the Sheet's current code to a .cpd or .txt file. Safe write (temp file + replace),
skips rewriting if the target file's content is already identical.
INPUTS:
- Sheet: Item - object - CalcpadSheet to save (from Play CPD or Search Variables)
- File: Item - string, optional - base name (without extension)
- Output Folder: Item - string, optional - destination folder
- CPD/TXT: Item - bool, optional (default false) - false = .cpd, true = .txt
- Execute: Item - bool (default false) - true = save
OUTPUTS:
- Save Path: Item - string
- Success: Item - bool

h. GH_Calcpad_Export_html.cs ("Export HTML" / ExportHTML)
Exports Calcpad's own rendered HTML report - same worksheet template/CSS the real Calcpad
desktop app and CLI use.
INPUTS:
- Sheet: Item - object - CalcpadSheet to export (from Play CPD or Search Variables)
- File: Item - string, optional
- Output Folder: Item - string, optional
- Execute: Item - bool (default false)
OUTPUTS:
- HTML Path: Item - string
- Success: Item - bool

i. GH_Calcpad_Export_pdf.cs ("Export PDF" / ExportPDF)
Same rendered report exported to PDF via wkhtmltopdf.exe (vendored, the same binary and
CLI arguments Calcpad's own CLI uses).
INPUTS: (same as Export HTML)
OUTPUTS:
- PDF Path: Item - string
- Success: Item - bool

j. GH_Calcpad_Export_word.cs ("Export Word" / ExportWord)
Same rendered report exported to a native .docx via Calcpad.OpenXml.OpenXmlWriter (real
OMath equations, no Word installation or COM automation).
INPUTS: (same as Export HTML)
OUTPUTS:
- Word Path: Item - string
- Success: Item - bool

WORKFLOW INTEGRATION
======================

BASIC:
Load CPD -> Play CPD -> Export/Save

SELECTIVE:
Load CPD -> Search Variables -> Play CPD -> Export/Save

FULL:
Load CPD -> Search Variables -> Play CPD -> Search Results -> Export/Save

OPTIMIZATION (Galapagos / Wallacei / Octopus):
Same as Full, with both Search components' Filter Names left empty (auto 'gh_'/'ghc_'),
wired directly into the optimizer's genome/fitness.
